# План RL v3: почему обученная политика берёт лишь часть аналитического оптимума

Зафиксирован 23 октября 2026 до запуска. Код `recsys/rl_distill.py`, тесты `tests/test_rl_distill.py`. Только selection; confirmation и final test не оцениваются.

## Наблюдение из RL v2

Аналитический оптимум π* ∝ π_ref·exp(r/β), посчитанный на оценочных контекстах, при «дослушивании» β=0,03 даёт NDCG +7,6% и награду +3,6%. Обученный точным градиентом RL на 8192 train-контекстах (2000 шагов × 64 = 15,6 прохода) получает 33–45% прироста цели. Проверочная J выходит на плато к 250–500 шагу, а проверочный KL продолжает расти: политика всё дальше уходит от reference без выигрыша на новых контекстах.

## Три объяснения и опыт на каждое

| Объяснение | Проверка | Источник идеи |
|---|---|---|
| Переобучение на малом пуле контекстов | Обратная KL на 8192 контекстах (15,6 прохода) против 65 536 (~2 прохода) | протоколы RLHF: 0,5–1 эпоха по уникальным контекстам |
| Направление дивергенции | При пуле 65 536: обратная KL(π‖π*) = −J/β + const (наш RL), прямая KL(π*‖π) (дистилляция π*), их среднее — Джеффрис | Go et al., ICML 2023 (f-DPG); Sessa et al., 2024 (BOND) |
| Порча общих эмбеддингов треков | Прямая KL при пуле 65 536 с замороженной таблицей эмбеддингов (она же выходной слой) | — |

Две настройки: «дослушивание» β=0,03 (лучший аналитический результат) и «секунды» β=0,3 (лучший компромисс RL v2). Итого 10 обученных вариантов, по 2000 шагов × 64, lr 5e-5, AdamW без weight decay, dropout выключен, фиксированный последний шаг.

## Общая для всех награда

RM v2 (среднее seeds 0 и 1) считается по топ-1024 трекам π_ref каждого контекста. Остальные треки получают взвешенную по π_ref среднюю награду топ-1024, так что их относительная масса в π* не меняется. Этим же π* задаются все три дивергенции. Для «секунд» награда домножается на нормированную длину до усреднения.

Дополнительно без обучения: аналитический оптимум с той же усечённой наградой для топ-K ∈ {20, 50, 200, 1024} на оценочных контекстах — сколько выигрыша даёт перевзвешивание только лучших кандидатов (как ARGS / controlled decoding).

## Оценка и вывод

Как в RL v2: NDCG@10/Recall/HitRate на 492 активных, 5%-допуск, награда по обучающей RM и по судье (seed 2) по полному каталогу, KL, PairAccuracy политики на реальных исходах selection-дня, поведение топ-10, доля аналитического прироста. Кривые J, KL и NDCG каждые 250 шагов — диагностика динамики, по ним ничего не выбирается.

Если большой пул сокращает разрыв — главная причина в переобучении контекстов. Если прямая KL или Джеффрис лучше обратной при равном пуле — дело в направлении дивергенции. Если заморозка эмбеддингов помогает — в общем выходном слое. Победителя по selection не объявляем; кандидаты для финального теста фиксируются отдельным документом.
