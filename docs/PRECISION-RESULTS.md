# Опыт с точностью вычислений: результат

Запуски `precision-fp32-20261025-01` и `precision-fp16scaled-20261025-01`, Windows, 25 октября 2026, по 936 и 940 с, статус `completed` (задача `Debug-Precision-20261025-01`, 108 тестов прошли до запуска). План с правилами чтения написан до запуска — [PRECISION-PLAN](PRECISION-PLAN.md); код `recsys/rl_distill.py` (`--precision`, `--cache-fp32`, `--grad-diagnostic`), тесты `tests/test_precision.py`. Исследовательские расчёты на окне selection; confirmation, final и новая когорта не затрагивались. Результаты — `research/results/runs/precision-*/`.

Вопрос: объясняется ли плато RL v3 (31–44% прироста цели J, NDCG@10 без изменения) тем, что обучение шло в FP16 без масштабирования потерь с наградами в float16? Условия те же, что в RL v3: опорная политика 0,1473, пул 65 536 контекстов, 2000 шагов × 64, lr 5e-5, seed и порядок батчей те же.

## Результат обучения

«Доля» — `share_of_analytic_gain`, доля прироста J до аналитического оптимума с полной наградой. Для исторических строк числа из [RL-V3-RESULTS](RL-V3-RESULTS.md).

| Рука | FP16 (исторический) | FP32 + награды в FP32 | FP16 с масштабом потерь |
|---|---|---|---|
| «Дослушивание» β=0,03, обратная KL: доля / NDCG@10 | 0,437 / 0,1477 | 0,434 / 0,1482 | 0,434 / 0,1486 |
| то же, прямая KL | 0,422 / 0,1462 | 0,420 / 0,1462 | 0,420 / 0,1464 |
| «Секунды» β=0,3, обратная KL | 0,378 / 0,1482 | 0,372 / 0,1488 | 0,376 / 0,1489 |
| то же, прямая KL | 0,415 / 0,1484 | 0,417 / 0,1485 | 0,413 / 0,1489 |

Разность NDCG@10 с опорной политикой (0,1473) во всех двенадцати строках мала, интервал 95% содержит ноль. Например, FP32, «дослушивание», обратная KL: +0,0009 [−0,0050; +0,0064]; «секунды», обратная KL: +0,0016 [−0,0017; +0,0047]. Средняя длина top-10 осталась 195 с («дослушивание») и 214 с («секунды»).

**Правило из плана:** FP16 существенен, если доля вырастает не менее чем на 0,15 или интервал NDCG строго выше нуля. Ни то ни другое не выполнено: максимальное изменение доли — 0,006. **FP16 без масштабирования не объясняет плато**; результат RL v3 не сводится к артефакту точности.

## Диагностика градиентов (без обновления весов)

Среднее по четырём первым обучающим батчам; эталон — FP32. «Нулей» — доля элементов градиента, равных нулю точно (в FP32 около 0,0001).

| Точка | Режим | Косинус с FP32 | Относительная L2-ошибка | Нулей |
|---|---|---:|---:|---:|
| начало обучения, «дослушивание» | FP16 | 0,99989 | 0,015 | 0,443 |
| | FP16, масштаб 1024 | 1,00000 | 0,001 | 0,414 |
| | bf16 | 0,99994 | 0,011 | 0,000 |
| конец обучения, «дослушивание» (обратная KL) | FP16 | 0,99919 | 0,040 | 0,116 |
| | FP16, масштаб 1024 | 0,99999 | 0,004 | 0,000 |
| | bf16 | 0,99960 | 0,028 | 0,000 |
| начало обучения, «секунды» | FP16 | 0,99898 | 0,046 | 0,464 |
| конец обучения, «секунды» (обратная KL) | FP16 | 0,99898 | 0,049 | 0,193 |

В FP16 без масштабирования 44–46% элементов градиента в начале и 12–19% в конце обнуляются (в эмбеддингах до 58%), но это малые по величине элементы: направление градиента совпадает с FP32 (косинус ≥ 0,998), норма совпадает (отношение 0,99–1,00). Масштаб потерь 1024 почти полностью убирает ошибку. Диагностика описывает эти батчи и эти две точки обучения и не доказывает отсутствие эффекта на другом бюджете.

## Что это означает для выводов

- Ограничение FP16 (F-FULL-002 в аудите) для RL v3 проверено и не подтверждено как причина. Строка «возможное влияние FP16» в разделе об ограничениях отчёта остаётся для RL v2/E2, где численно не перепроверялась, но для дистилляции v3 влияния нет.
- Остальные объяснения плато (ёмкость выходного слоя, бюджет шагов и lr, отсутствие попарных признаков) этим опытом не проверены; E1 и совместное обучение ([JOINT-PLAN](JOINT-PLAN.md)) относятся к ним.
- Предложение сравнить с FP32 «только награды» (запуск C из плана) не понадобилось: запуск A уже совпадает с историческим.
