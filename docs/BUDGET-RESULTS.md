## Чтение по правилам плана

**Бюджет не объясняет плато.** Для «дослушивания» доля прироста J не выросла, а упала (0,32 против 0,44; порог «причина — бюджет» 0,59), интервал разности NDCG с опорной содержит ноль (+0,0022 [−0,0046; +0,0085]). Для «секунд» доля отрицательная (J финальной политики ниже J опорной при KL 0,075 против 0,029): при тройном lr политика уходит дальше от опорной, но не ближе к оптимуму. NDCG при этом не меняется. Кривые J и NDCG колеблются на плато без тренда и при 8000 шагах.

Отрицательный результат подкрепляет прежний вывод: RL весов GPT-2 без признаков пары не повышает релевантность ни при числе шагов 2000, ни при 8000, ни при lr 5e-5, ни при 1,5e-4.

## Ограничения

Бюджет и lr менялись вместе (по плану), поэтому нельзя отделить их вклад; ухудшение доли при большем lr может быть признаком нестабильности. Один seed, один способ обучения, selection использовалось многократно.
