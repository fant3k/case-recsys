# Устранение самоподкрепления повторов при генерации пяти треков

Статус: план, написан до запуска (25 октября 2026). Только окно selection, без нового обучения; confirmation, final и новая когорта не затрагиваются. Результаты — `docs/MULTISTEP-FIX-RESULTS.md`.

## Проблема

При последовательной генерации выбранный трек добавляется в контекст как прослушанный, и приоритет повторов PPS ([GLOSSARY](GLOSSARY.md)) считает его в счётчике и усиливает при следующем выборе. В [MULTISTEP-V2-RESULTS](MULTISTEP-V2-RESULTS.md): при жадном выборе 70–98% треков на шагах 2–5 повторяют уже выбранный, в 95–100% пятёрок есть дубликат.

## Что сравнивается

Те же политики (опорная и B), жадный выбор, отклик на сгенерированный трек — прогноз судьи (RM v2 seed 2), выдача пяти треков для всех 1000 warm-пользователей, NDCG@5 (стандартный: позиции сохраняются, повтор не даёт прироста) по 492 активным:
- `static_top5` — пять лучших треков реального контекста (контроль, без генерации);
- `seq` — прежняя последовательная генерация;
- `seq_ban` — `seq` с запретом выбирать уже выбранный в пятёрке трек;
- `nopps` — сгенерированные события не входят в счётчики PPS (счётчики считаются только по реальной истории; остальной вход модели прежний);
- `nopps_ban` — `nopps` и запрет повторов.
Меры: NDCG@5, число попаданий в реальные будущие прослушивания, число уникальных треков в пятёрке, доля пятёрок с дубликатом, пересечение с `static_top5`. Парные 95% интервалы разностей по пользователям.

## Правила чтения (заданы заранее)

- **Самоподкрепление устранено механизмом PPS**, если доля пятёрок с дубликатом у `nopps` (без запрета) ниже 50% при том, что у `seq` она 95–100%. Отсутствие дубликатов у вариантов с запретом — свойство алгоритма, а не результат.
- **Релевантность улучшается**, если NDCG@5 `nopps_ban` или `nopps` выше `seq`/`seq_ban` с нижней границей интервала разности выше нуля; если интервал содержит ноль или ниже, пишем «релевантность не улучшилась».
- Результат не заменяет и не меняет подтверждающих гипотез, не включает реальных реакций пользователей (отклик — прогноз модели), один день, один способ декодирования; исследовательский.
