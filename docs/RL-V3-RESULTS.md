## Выводы по трём объяснениям

1. **Переобучение на малом пуле — частичное объяснение.** Для «дослушивания» 65 536 контекстов против 8192 поднимают долю аналитического J с 0,31 до 0,44, PairAccuracy с 0,534 до 0,541; NDCG −0,1% → +0,3% (разница внутри шума). Для «секунд» эффекта нет (0,39 против 0,38). Разрыв до оптимума остаётся большим.
2. **Направление дивергенции почти не влияет.** При равном пуле обратная, прямая и Джеффрис дают долю 0,42–0,44 для «дослушивания» и 0,38–0,42 для «секунд»; различия NDCG внутри интервалов. Гипотеза, что дистилляция π* (прямая KL, как в f-DPG/BOND) обобщается лучше обратной, на этих данных не подтвердилась.
3. **Заморозка общих эмбеддингов не помогает.** Для «дослушивания» доля 0,40 против 0,42 у прямой KL без заморозки; для «секунд» заморозка ограничивает движение (доля 0,18, KL 0,011, секунды +2,1% вместо +5,3%) — без эмбеддингов политика почти не может сдвинуться к длинным трекам. Порча общего выходного слоя главным ограничением не является.

**Главное наблюдение:** обученные политики тратят сопоставимый KL-бюджет (0,14–0,18 против 0,21 у оптимума топ-50) и получают ~половину прироста предсказанной награды, но **не получают прироста NDCG** (+7,6% у оптимума топ-50). Значит, сеть воспроизводит общий сдвиг к трекам с высокой наградой, но не воспроизводит пользовательски-специфичный порядок внутри 50 лучших кандидатов — именно ту часть, которая и даёт релевантность. Кривые проверки это подтверждают: J выходит на плато к 500–1000 шагу, NDCG колеблется 0,145–0,152 без тренда. Это интерпретация, не доказанная отдельным опытом.

> Позднее (25 октября): когда выход политики получает попарные признаки, обучение весов вместе с головой тоже даёт прирост NDCG — [JOINT-RESULTS](JOINT-RESULTS.md); утверждение ниже относится к обучению без таких признаков.

**Практическое следствие (гипотеза для итогового отчёта, не результат):** выигрыш RM v2 по «дослушиванию» доступен при выдаче как перевзвешивание топ-50 кандидатов π_ref по RM (аналог controlled decoding / reranking), а не через обучение весов политики. Это требует вызова RM на 50 кандидатов на запрос.

## Ограничения

Один seed на вариант; окно selection теперь оценено ещё для 21 строки (всего десятки политик) без поправки на множественность, поэтому выбор лучшей строки по нему оптимистичен. Судья обучен на тех же логах. Награды — прогнозы RM, не наблюдённый отклик. «Доля» считается относительно оптимума с полной наградой, а обучение шло на усечённой до топ-1024 (её собственный оптимум даёт +3,0% награды против +3,6%), так что потолок для обученных вариантов несколько ниже 1. Победителя не объявляем; кандидаты для финального теста фиксируются отдельным документом до его открытия.
