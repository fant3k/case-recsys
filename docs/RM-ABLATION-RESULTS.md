## Чтение по правилам плана

**Сигнал лежит в признаках пары пользователь–трек.** Перевзвешивание по RM без этих признаков не лучше опорной (интервал строго ниже нуля), а по RM с признаками выигрывает значимо. Общий вход модели награды (история, эмбеддинг трека, отклик) без признаков пары сам по себе выигрыша не даёт: он даже слегка ухудшает порядок. Это согласуется с остальной картиной: голова E1 без попарных признаков не помогает, совместное обучение и голова с признаками помогают, а supervised-контроль без модели награды — нет.

## Ограничения

Один seed модели награды без признаков (других нет), исследовательский опыт на selection. RM без признаков — одна модель, а не ансамбль, поэтому сравнивается с одной полной моделью того же seed. Признаки пары — счётчик, давность и прошлая доля дослушивания пары: частично это то же, что считает частотное правило, так что результат не показывает, что RM знает больше простого правила (частота + давность даёт 0,1874 на selection).
