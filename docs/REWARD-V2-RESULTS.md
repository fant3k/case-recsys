# Модель награды v2: результат

Запуск `reward-v2-20261022-01`, Windows, 22 октября 2026, 995 с. Код `recsys/reward_v2.py`, тесты `tests/test_reward_v2.py` (53 теста всего прошли; оценка по всему каталогу совпадает с путём обучения; признаки только из истории до целевой группы). Confirmation и final test не оценивались, ничего не выбиралось по selection.

> Историческая запись запуска. Формулировки об атрибуции признакам и причинах слабого RL уточнены в [REPORT](../report/REPORT.md) (раздел о модели награды): сравнение «ансамбль из трёх с признаками против одной модели без признаков» смешивает признаки и ансамблирование.

## Постановка

- Цель как в v1: min(played_ratio, 100)/100 на залогированных прослушиваниях.
- Основа — копия GPT-2 с откликом во входе (`pps-20261022-01/full+pps+fb/last.pt`), дообучается вместе с головой (lr 1e-4 основа, 1e-3 голова, AdamW wd 0,01, 4000 шагов × 64, фиксированный последний шаг).
- Голова: [h, эмбеддинг кандидата, их произведение, 9 признаков кандидата из контекста, флаг is_organic целевого события]. Признаки: log число прослушиваний трека в контексте, давность, был ли, средняя доля дослушивания пары, длина и популярность трека (train), средняя доля дослушивания и доля органики пользователя в контексте, длина контекста.
- Флаг is_organic — условие: при оценке рекомендаций RL он всегда 0.
- Ансамбль 3 seed + абляция без признаков (seed 0).
- Оценка: все 17 669 залогированных in-catalog событий selection-дня (как аудит v1), 49,5% из них рекомендованные.

Парные 95% bootstrap по пользователям:

- macro MAE: ансамбль − v1 −0,0706 [−0,0809; −0,0604]; − среднее по треку −0,0906 [−0,1019; −0,0792]; − без признаков −0,0095 [−0,0114; −0,0074]. Последнее сравнивает ансамбль из трёх моделей с одной моделью без признаков, поэтому смешивает признаки и ансамблирование. При одинаковом seed 0 macro MAE с признаками равна 0,2938, без них 0,2895 (сохранённый JSON), то есть самостоятельный выигрыш признаков по MAE не подтверждён.

По типу трека PairAccuracy ансамбля: недавние 0,500, только старые 0,559, новые 0,564 (среднее по треку 0,561 / 0,541 / 0,540).

Разброс ансамбля: среднее std 0,036, 90-й перцентиль 0,070. Флаг is_organic почти не влияет на прогноз: 0,685 при 0 против 0,690 при 1.

## Выводы

1. v2 намного точнее v1 по ошибке (MAE −29%), калибровка лучше. Модель без явных признаков (одиночная) уже даёт EventMAE 0,256; вклад признаков повторов отдельно не изолирован (см. сравнение при одном seed выше).
2. **Внутри пользователя v2 упорядочивает треки не лучше простого среднего по треку** (0,554 против 0,555), а на недавних повторах — на уровне монетки. Улучшение MAE не сопровождается улучшением этой метрики попарного выбора. Объяснение через состояние сессии остаётся гипотезой.
3. Для RL это ключевое ограничение: различия награды между кандидатами одного пользователя, по-видимому, в основном отражают свойства самого трека (длина, популярность, средний отклик), а не персональный вкус; это гипотеза, которую PairAccuracy не доказывает. Тогда рост предсказанной награды при RL был бы в первую очередь сдвигом к таким трекам.
4. v1, на которой выполнен прежний RL, внутри пользователя почти случайна (0,506; на рекомендованных 0,478). Это согласуется со слабым движением прежнего RL и его сдвигом к длинным трекам; причинная связь здесь не проверялась и остаётся гипотезой.
5. Флаг is_organic модель почти не использует: режим прослушивания она, видимо, уже видит по доле дослушивания недавних треков в контексте.

Один запуск на seed, одно окно. Флаг is_organic как условие — допустимый вход (при рекомендации известен и равен 0), не утечка отклика.
