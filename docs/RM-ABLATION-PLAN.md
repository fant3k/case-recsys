# Где в модели награды лежит выигрыш кандидата A

Статус: план, написан до запуска (25 октября 2026). Только окно selection; confirmation, final и новая когорта не затрагиваются. Результаты — `docs/RM-ABLATION-RESULTS.md`.

## Вопрос

Перевзвешивание топ-50 опорной политики по модели награды (A) подтверждено на финале и новых пользователях. Из чего состоит сигнал модели награды: из признаков пары «пользователь–трек» (счётчик, давность, прошлая доля дослушивания пары) или из остального входа (история и эмбеддинг трека)? В [REWARD-V2-RESULTS](REWARD-V2-RESULTS.md) есть обученная на тех же данных и с той же основой модель без этих признаков (seed 0).

## Что делается

То же перевзвешивание (β = 0,03, топ-50, FP32-оценка), по одной модели: (1) RM v2 seed 0 с признаками; (2) RM v2 seed 0 без признаков пары; (3) ансамбль seeds 0 и 1, как в A. Селекция, 492 активных пользователя, парный bootstrap 95%.

## Правила чтения (заданы заранее)

- **Сигнал в признаках пары**, если A с RM без признаков не лучше опорной (интервал разности с опорной содержит ноль или ниже) при том, что A с полной RM seed 0 лучше (нижняя граница выше нуля).
- **Сигнал и вне признаков пары**, если A с RM без признаков тоже строго лучше опорной; тогда доля вклада признаков оценивается по разности «полная − без признаков» с её интервалом.
- Любой исход публикуется. Один seed RM, исследовательский опыт, новых кандидатов не создаёт.
