# Разброс кандидата B по seed

Статус: план, написан до запуска (25 октября 2026). Только окно selection; confirmation, final и новая когорта не затрагиваются. Результаты будут в `docs/BSEEDS-RESULTS.md`.

## Вопрос

Кандидат B — RL «секунды», β = 0,3 ([FINAL-CANDIDATES](FINAL-CANDIDATES.md)) — обучен с одним seed (выборка контекстов и порядок батчей). Устойчивы ли его свойства к seed: сохранение NDCG@10 в допуске 5%, рост ожидаемых секунд по судье и реально прослушанных секунд?

## Что делается

Те же настройки, что у B в `rl-v2-20261023-01` (8192 контекстов, 2000 шагов × 64, lr 5e-5, β = 0,3, награда «секунды»), с `--seed-offset 1` и `--seed-offset 2` (сдвиг seed выборки контекстов и порядка батчей на 1000·k); seed 0 — исходный запуск. Затем replay-проверка ([REPLAY-PLAN](REPLAY-PLAN.md)) для двух новых политик.

## Правила чтения (заданы заранее)

- B устойчив по seed, если на каждом из двух новых seed: нижняя граница mean(NDCG − 0,95·NDCG_ref) не ниже нуля (допуск 5% поддержан), ожидаемые эквивалентные секунды судьи выше опорных и реально прослушанные секунды не ниже опорных.
- Если хотя бы один показатель нарушается на одном seed, в отчёте пишется «B неустойчив по seed» с цифрами.
- Новые политики не заменяют кандидата B и не выбираются по результату; число seed (три) не превращает исследовательский опыт в подтверждённую гипотезу.
