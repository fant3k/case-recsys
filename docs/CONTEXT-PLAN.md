# Длинный контекст: сокращается ли разрыв базовой GPT-2 с частотой

Статус: план, написан до запуска (25 октября 2026). Только окно selection; confirmation, final и новая когорта не затрагиваются. Результаты — `docs/CONTEXT-RESULTS.md`. Исследовательский опыт: заменой опорной политики или кандидатов он не является.

## Вопрос

Базовая GPT-2 видит 128 последних событий, а около половины будущих положительных пар встречались только до этого окна ([GAP-DIAGNOSTICS-RESULTS](GAP-DIAGNOSTICS-RESULTS.md)); приоритет повторов PPS считает счётчики только внутри окна. Сокращается ли разрыв с личной частотой, если увеличить окно при том же рецепте и том же времени обучения?

## Что делается

Опорный рецепт `full+pps+fb` (обучение на всех позициях, PPS, отклик во входе, dropout 0,1, weight decay 0,01, lr 5e-4, batch 64, 600 секунд обучения), отличается один фактор — длина окна контекста `--context-size`: 256 и 512 (опорная 128). Время обучения то же (600 с на руку), поэтому более длинный контекст успевает меньше шагов; это часть сравнения «при том же вычислительном бюджете». Если 512 не помещается на 12 ГБ при batch 64, берётся batch 32 для этой руки с пометкой. Метрика — NDCG@10 на selection (492 активных). Известные значения опорного рецепта на контексте 128 ([FULLSFT-RESULTS](FULLSFT-RESULTS.md)): на шаге 0 (необученная модель, один приоритет повторов PPS) 0,1726, после 600 с обучения 0,1473 (так выбрана опорная политика: фиксированный последний шаг); личная частота 128 событий — 0,1805. В отчёте для каждой длины приводятся обе точки (шаг 0 и последний шаг, 600 с).

## Правила чтения (заданы заранее)

- Длинный контекст **сокращает разрыв**, если NDCG@10 после 600 с обучения выше 0,1473 (последний шаг опорного рецепта) для длины 256 или 512; разрыв с частотой при этом считается как 0,1805 минус это значение.
- Если NDCG после обучения не выше 0,1473, пишем «длинный контекст при том же бюджете разрыв не сокращает». Отдельно приводится значение на шаге 0: оно показывает, сколько даёт один приоритет повторов при длинном окне (на 128 оно 0,1726); если оно выше, это эффект длинного окна на счётчики PPS, а не обучения.
- Любой исход публикуется. Это не заменяет опорную политику: все RM, RL, A, B, E1 и подтверждающие результаты остаются на контексте 128. Новых кандидатов для final и новой когорты не создаём; один seed, selection использовалось многократно.
