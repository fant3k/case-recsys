## Что видно

- **Здесь RL берёт почти весь аналитический прирост награды: 91–96%**, тогда как для награды «дослушивание» в RL v2 и v3 обученные политики получали 31–45% ([RL-V3-RESULTS](RL-V3-RESULTS.md)). Квантиль в основном описывает свойство самого трека (простое среднее по треку даёт PairAccuracy 0,782 против 0,754 у ансамбля), поэтому для неё достаточно общего сдвига логитов по трекам, который выходной слой выучить может. Для «дослушивания» нужен порядок внутри 50 кандидатов, зависящий от пары пользователь–трек. Это согласуется с объяснением через выразимость выходного слоя, но не доказывает его: другая награда меняет сразу несколько вещей.
- **При β = 0,3 награда растёт без потери релевантности:** +7,7% по обучающей RM и +6,8% по судье, NDCG@10 0,1477 (+0,0004 [−0,0034; +0,0046]), допуск 5% поддержан, длина top-10 213 с против 202 (+5%), уникальных треков 6434 против 6658. Это ответ на вопрос задания «можно ли увеличить награду без заметной потери точности» для награды, нормированной по длине.
- **Длину квантиль полностью не убирает:** нормировка внутри корзин длины не устраняет сдвиг (213 с при β = 0,3, 226 с при β = 0,1, 250 с при β = 0,03), и по величине сопоставим со сдвигом у «секунд» при β = 0,3 (≈216 с); отличие в том, что при β ≥ 0,3 он не сопровождается падением NDCG.
- **Компромисс как и раньше:** β = 0,1 даёт +20% награды при −7,3% NDCG; β = 0,03 — +37% награды и −39% NDCG, выдача схлопывается (3440 уникальных треков).
- Offline-варианты (продолжение SFT, Exp-RSFT) снижают NDCG на 0,009–0,013; при близкой награде (Exp-RSFT λ = 0,3: +7,6%, RL β = 0,3: +7,7%) RL сохраняет NDCG, а Exp-RSFT теряет 0,011.
- PairAccuracy политик на реальных исходах дня почти не меняется (0,506–0,532 против 0,531 у опорной); награда растёт без улучшения попарного выбора внутри пользователя.

## Ограничения

Один seed, одно окно, selection использовано многократно: числа нельзя считать подтверждением. Квантильная модель награды хуже простого среднего по треку внутри пользователя (0,754 против 0,782), судья обучен на тех же логах. Рост «награды» — прогноз модели, не наблюдённое время слушания. Объяснение через выразимость — гипотеза.
