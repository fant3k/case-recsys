# Исторические версии кода

Финальный тест и проверка на новой когорте записали SHA256 всего кода в `locked-manifest.json` до загрузки событий. После этих запусков несколько модулей исправлялись. Исправления не меняют сохранённые результаты, но текущие файлы уже не совпадают с хэшами манифестов. Здесь лежат точные версии, которые использовались в запусках; их SHA256 совпадают с манифестами.

| Запуск | Файл | Что изменилось позже |
|---|---|---|
| `final-test-20261023-01` | `recsys/rl_v2.py`, `recsys/rl_distill.py` | фильтр пользователей без истории до среза (падение `day_row`), поле доли J к усечённому оптимуму в `rl_distill` |
| `final-test-20261023-01` | `recsys/reranker.py` | параметр `stats_data`: глобальные статистики по другой выборке пользователей (нужен для новой когорты) |
| `final-test-20261023-01` (также новая когорта и N3) | `recsys/final_test.py` | 25.10: маркер финального окна создаётся после расчёта хэшей входов (раньше до); версия запусков — в `final-test-20261023-01/recsys/final_test.py` |
| `new-cohort-confirmation-20261025-01` | `recsys/rl_v2.py`, `recsys/rl_distill.py` | 25.10: поле `share_of_analytic_gain` считается по итоговой политике, а не по последней точке кривой; версии запуска N3 — в `new-cohort-confirmation-20261025-01/recsys/` |
| `new-cohort-confirmation-20261025-01` (и `joint-seed*`) | `recsys/exploratory.py` | 25.10: руки `sft_kl:λ`, сохранение пользовательских строк и `vs_head_only`; версия запусков N3 и `joint-seed*` восстановлена обратным применением правок и совпадает с хэшем манифеста N3 |

Точные версии, использованные в запусках 23.10, лежат в `final-test-20261023-01/` |

Остальные модули, записанные в манифесты (`reward_v2.py`, `data.py`, `models.py`, `metrics.py` и другие), не менялись. Чтобы повторить исторический запуск с тем же кодом, подставьте эти файлы вместо текущих в `recsys/`.
